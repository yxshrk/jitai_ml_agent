## Claim
Add three binary auxiliary heads predicting whether play time reaches 25%, 50%, and 75% of
`min(duration_ms, 18000)`, while retaining the original long_view score for prediction.

## Mechanism (why it moves within-user ranking)
The ordered thresholds distinguish bounces from near misses that share the same long_view label. Their BCE gradients
regularise shared interaction embeddings, while task-specific biases prevent auxiliary calibration from directly
altering the main ranking head.

## How to implement on node_000
1. Read training `play_time_ms`; set `depth_fracs = [0.25, 0.50, 0.75]`.
2. Build `auxtr = play >= min(duration, 18000)[:,None] * depth_fracs`; mask rows with `duration_ms == 0`.
3. Add `Waux` with shape `(dim, 3)`, `Aaux` with shape `(3,)`, and matching Adam states.
4. Return the FM interaction scalar from `logits`; auxiliary logits are `Waux[X].sum(1) + inter[:,None] * Aaux`.
5. Add masked BCE with weight 0.1, normalized by three times the number of valid sampled rows.
6. Update `Waux` and `Aaux` from auxiliary gradients; keep the main `W` gradient BPR-only.
7. Add auxiliary interaction gradient only to shared `V`; keep the main long_view logit as prediction.

## Risks / failure modes
- The measured parent already used field-aware embeddings and BPR; only the +0.00016 seed-mean child delta is
  attributable to this auxiliary mechanism, not the parent's loss or representation.
- The thresholds are highly correlated and may add almost no information beyond long_view.
- Auxiliary gradients can damage ranking if applied to the main linear weights or weighted too strongly.
- Unknown-duration rows must be masked because their normalized watch-depth target is undefined.
