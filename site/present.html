0.6016 → 0.6056, zero mid-run interventions.

It trains a model that predicts which videos a user will keep watching, then diagnoses that model, changes it, retrains, and measures again, in a loop that no person steers. The score is the competition's ranking metric: how well the model orders each user's own videos.

the machine

Every iteration has four steps: diagnose, treat, retrain, measure.

01

DIAGNOSE

Looks at how the last model trained, pass by pass over the data, and names what is holding it back: overfitting, undertraining, a plateau, or plain run-to-run randomness (seed noise).

02

TREAT

Picks a fix from a library of 42 method cards. Each card is a published ranking technique written up with how it works, when it applies, and what it has scored on this dataset so far.

03

RETRAIN

The LLM writes a complete training script to a fixed input/output contract. The harness runs it for 360 s to catch crashes (a smoke test), then trains it on the same time-based data split every iteration.

04

MEASURE

The official evaluator scores how well the model ranks each user's own videos (GAUC and nDCG@5 per user, averaged into one primary score). A change is kept only if its gain clears the acceptance gate: a 0.0005 floor, and borderline gains must repeat on a second seed (a z-test). The run stops by the competition's rule: 3 iterations in a row without a 0.002 gain (epsilon).

the harness

The agent's judgment matters, but the harness matters just as much.

01

Structural leakage guard

The hidden test set is never copied into the agent's workspace, and generated code is screened before it runs. Not touching the test set is a property of the filesystem, not a promise in a prompt.

02

Calibrated acceptance gate

The baseline's run-to-run randomness is measured first (3 seeds, σ ≈ 0.0001), so every gain is read as a multiple of that noise (sigmas). Borderline gains above the 0.0005 floor must repeat on a second seed and pass a statistical test (a z-test) before acceptance.

03

Method cards, not vibes

The agent's knowledge is 42 cards: for each technique, how it works, when it applies, its citation, and what it has scored here. A two-tier menu separates proven fixes from promising but untested ones, and a strategy layer matches them to where the run is: opening, middle, or close.

04

Decision benches

The agent's judgment is tested like code: we froze real mid-run situations whose right next move we know, and replay the agent against them after every change, without a training run. Bench fixes may only be evidence corrections or general principles, never canned answers.

05

Agent plans the ensemble, code runs it

For the final move, combining several model types into one (an ensemble), the agent writes a structured, machine-checked plan and fixed code carries it out: quick trial fits of each model type, every combination scored, the winner retrained and re-verified in full. No LLM touches the measurement.

06

Telemetry-gated diagnosis

A diagnosis may only cite training curves that were actually recorded. When we found out-of-date notes quietly steering the agent's choices, we rebuilt how knowledge is loaded and disclosed the affected runs rather than hiding them.

the knowledge

Exactly 42 cards, from cited literature and our own measured evidence. One was invented by a run itself.

design principles

We never learn the recipe ourselves and hand it to the agent.

01

Clean runs

The submitted run starts from the published baseline with no seed scripts. We never learn the winning route ourselves and hand it back; the agent must find each turn itself.

02

Grounded action

Every move is one of 42 method cards: a cited technique with a mechanism, preconditions, and measured evidence. No arbitrary knob-turning.

03

Noise awareness

The baseline's run-to-run noise is measured first (σ ≈ 0.0001). Gains are read as multiples of it; borderline gains must repeat on a fresh seed and pass a statistical test before they count.

04

Learning from failure

Every hypothesis, dead end, and crash is journaled. A VOID stays on the chart. The 139-run ledger feeds the cards, so the agent inherits the useful lessons and not the noise.

05

Bounded authority

The agent chooses the next experiment and writes the script. The harness screens, trains, scores, gates, and stops. No LLM in the measurement path.
