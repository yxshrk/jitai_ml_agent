the machine

Diagnose, treat, retrain, measure. Repeat until the rule says stop.

01

DIAGNOSE

Looks at how the last model trained, epoch by epoch, and names what is holding it back: overfitting, underfitting, a plateau, or plain seed noise.

02

TREAT

Selects a treatment from a library of 42 method cards: mechanism, measured evidence on this dataset, and preconditions, drawn from ranking literature.

03

RETRAIN

The proposer LLM writes a complete training script against a frozen node contract, smoke-tests it in 360 s, then trains on the fixed temporal split.

04

MEASURE

The official evaluator scores GAUC and nDCG@5 per user; primary = the mean. A change is kept only if it clears a calibrated acceptance gate; the run ends when three consecutive iterations fail to improve the best by ε = 0.002.

accept only if Δ clears the gate · reject = dead end · stop after 3 quiet iterations

the harness

The agent is only half the system. The other half never trusts it.

Structural leakage guard

The hidden test window is never mounted into the agent's workspace, and generated code is screened before execution. Not touching the test set is a property of the filesystem, not a promise in a prompt.

Calibrated acceptance gate

Baseline seed noise is measured first, so every gain is read in sigmas. Borderline gains must repeat on a second seed (a z-test) before acceptance, and a convergence rule ends the run, never a person.

Method cards, not vibes

The agent's knowledge is 42 cards: mechanism, preconditions, and measured evidence per technique. A two-tier menu separates proven treatments from ranked opportunities, and a strategy layer matches them to the run phase.

Telemetry-gated diagnosis

A diagnosis may only cite curves that were actually recorded. When we found stale knowledge silently mis-steering selection, we rebuilt the channel and disclosed the discarded runs rather than hiding them.

Typed ensemble plans

For the closing move, the agent emits a typed, schema-validated plan and a deterministic assembler executes it: parallel family probes, exhaustive blend enumeration, full-fidelity re-verification. No LLM in the measurement path.

Decision benches

Selector quality is tested like code: frozen run-state fixtures with known right answers, replayed against the brain after every change. Bench fixes may only be evidence corrections or general principles, never canned answers.

the experiments

139 runs. These are the numbers that survived.

+0.0013 vs +0.0003

Cross-family blends beat same-family seed ensembles by an order of magnitude. Strong package first, cross-family close: the endgame shape.

k = 3 … 12 flat

Blend member count does not matter on Pure: 3 to 12 all land in 0.6048-0.6050, within noise.

k = 16

Embedding width is dataset-sized: 16 optimal on Pure; peak near 48 on the 8x larger 1K.

+0.0004, killed

ε = 0.002 silently kills honest small steps from a strong base; hence a gate calibrated in sigmas.
