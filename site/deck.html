Architecture

One iteration = one auditable research decision

Diagnose

Read the champion's learning curves and the run journal.

→

Decide

Select one cited card from a 42-card method library; record a rejected alternative.

→

Fan out

One node may run a full sweep: probes, halving, finals. Every probe logged.

→

Judge

Sigma-gated accept/reject vs a seed-calibrated noise floor; official convergence stop.

Agent (LLM)

gpt-5.6-sol as selector / proposer / reflector, gpt-5.4-mini as fixer. Chooses the research move, writes whole-file changes, critiques itself.

Harness (deterministic)

Owns seeding, timeouts, evaluation, acceptance, rollback, budgets, stopping. The agent never improvises the accounting.

Design choices

Why it is built this way

Strict division of labor

Agent proposes; harness executes and scores. Interventions are machine-verifiable: every journal record carries an intervention boolean.

Mechanical seeds

Seed 42 explores; wins confirm at 42/43/44. A win must clear the 0.002 epsilon floor; grey-zone gains need reseed repeatability at z ≥ 2.

Structural leakage guards

Hidden test physically absent from the agent workspace; final models retrain on train only; predictors assert no label-like arrays.

Cited knowledge, not vibes

42 method cards with measured annotations. Discoveries are distilled back in; later runs cite them as evidence.

Typed endgame

The agent plans a cross-family ensemble close as data; the harness executes it: probes → blend map → full trains → re-verify.

Negative results are first-class

Refuted directions stay on the ledger with their numbers, preventing repeated failures across runs.

The designated run · recorded replay

run_bigclock_07: six decisions, no seed script

  • Launched with no executable solution or checkpoint; reproduced the baseline at 0.601838 (published 0.6016)
  • Ran its own two-stage hyperparameter search inside one node: dropout 0.18, weight decay 9e-5, LR ×0.57 — non-obvious dials, later reproduced from scratch (0.60561)
  • Designed its own ensemble: trained 7 seed members, validation-selected 3, per-user rank average → 0.605575
  • Stopped itself under the official ε=0.002 / N=3 rule after 6 iterations
  • 17.0 minutes, 115,315 tokens, CPU only, 0 mid-run interventions

Reliability engineering

We test the agent's judgment like code

The failure → the fix

  • Live run farm_f1 made a measurably wrong endgame call: same-family close whose ceiling could not clear epsilon; converged early
  • Froze that exact decision state as a benchmark fixture
  • Root cause: stale convergence-pressure guidance
  • Fixed with a general epsilon-arithmetic principle, not a scenario-specific answer — bench 3/3, corrected run relaunched

Decision benches gate everything

  • Frozen decision states + expected judgments = a regression suite for reasoning
  • Top model tier passes all six scenarios at low reasoning effort
  • Workhorse tier needs medium effort for the hardest scenario
  • No prompt or knowledge fix ships without a passing bench

Experiments · negative results

What the ledger refuted

Measured dead on Pure

  • Sequence modeling: affinity prerequisite 0.6035, DIN-lite correctly gated off
  • Watch-time objectives: ordinal 0.6033, censored auxiliary 0.6022 — below epsilon
  • Listwise losses, attention, extra crosses, hard-negative BPR, post-hoc run blending

Less is more

  • Official 5-field L0 model: 0.604335 at seed 42
  • Kitchen-sink L5: 0.601740 — more fields hurt
  • The plateau at 0.6045–0.6055 appears structural at this scale; capacity and identities mostly overfit

Scoped experimental findings at this dataset scale, not claims that a method family can never work.

Bonus benchmark

KuaiRand-1K: a discovery that had to survive an audit

The discovery

  • 48-cell factorial run found a regime inversion vs Pure: pure logloss, no recency → 0.6524
  • run_omega_1k then discovered causal session features (gap since last impression, session position, hour/weekday crosses): +0.019 → 0.66892
  • Second independent run reproduced the mechanism at +0.022

The audit, before we believed it

  • Independent tie-aware re-evaluation: exact match
  • Fresh-seed replications: 0.674 / 0.677
  • Within-hour row-shuffle invariance: 0.66517 held
  • Carded and measured on Pure by a later run: +0.0002 — an honest negative, as predicted

Further improvements

What we would do next

Better stopping science

The official rule ends runs while genuinely improving (real gains here are sub-epsilon). A principled sequential-testing stop rule would be better science.

Scale the loop

Compliant 27K agent runs via subsampled calibration or bigger hardware; sigma recalibration per model family.

Reliable ensemble close

Snapshot members and member-diversity design to make the close reliably positive; implemented, under-tested.

Mixed-provider proposers

A second proposer found a novel working package (click-aux rider, 0.60477); a proposer ensemble is the obvious next step. Broaden search beyond greedy improve-best.
