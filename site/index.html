the machine

Diagnose, treat, retrain, measure. Repeat until the rule says stop.

No human picks the next move. The agent reads its own training curves, chooses a treatment from a library of cited method cards, edits the model code, retrains, and keeps only what measures above an ε = 0.002 bar. A convergence rule, not a person, ends the run.

01 · DIAGNOSE

Every trained node logs a learning curve: training loss and validation score at every epoch. The agent reads that curve the way an engineer would. Validation peaking early and then sliding while training loss keeps falling means overfitting. Both still improving at the last epoch means undertraining. A flat curve on a changed model means the idea did nothing. And because the run calibrates baseline seed noise first (3 seeds, σ ≈ 0.0001), the agent can tell a real effect from a lucky seed by reading the gap in sigmas. A telemetry gate keeps it honest: a diagnosis may only cite a curve that was actually recorded, and every diagnosis is written verbatim into the journal, so wrong calls stay visible. The one you see replayed below, "validation peaks at epoch 8", is what steered the whole run.

02 · TREAT

The diagnosis selects from a library of 42 method cards, each a real technique from the ranking literature written down with its mechanism, when it applies, and what it has measured on this dataset so far. Overfitting points at regularization cards; a plateau points at ensembling or a family switch. The menu has two tiers, proven treatments versus evidence-ranked opportunities, and a strategy layer keeps the run phase-appropriate: establish a strong base first, exploit what measured, close with a cross-family ensemble.

03 · RETRAIN

The agent then writes a complete training script implementing the chosen treatment, against a frozen contract: read the prepared splits, train, emit validation predictions plus the per-epoch history the next diagnosis will need. A 360-second smoke test catches crashes before the full train. The hidden test window is never mounted into the workspace, so leakage is impossible by construction rather than by instruction. If a script crashes, a fixer model gets one repair attempt; an unrecoverable crash is logged VOID and the loop moves on.

04 · MEASURE

The official evaluator scores validation GAUC and nDCG@5 per user; the primary metric is their mean. A change is kept only if its gain clears an acceptance floor, and borderline gains must repeat on a second seed (a z-test against the calibrated noise). Convergence is the competition rule: three consecutive iterations within ε = 0.002 ends the run, hard cap 50. The run you are about to scroll through ended exactly that way, with no human in the decision.

the evidence

What the diagnosis looked like inside the model.

While a model trains, every video grows an embedding. A video the model has barely seen should keep a small one: there is not enough data to learn anything real about it. Watch the red line below, the rarest 10% of videos. In the baseline it never stops growing: the model is memorizing those videos.
